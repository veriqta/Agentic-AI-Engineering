# Module 08. Multi-Agent Systems

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 29 to 32 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 29 | Multi-Agent System Design | Specialist roles, delegation, task contracts and comparison with single-agent alternatives. |
| [Week 02](week-02/README.md) | 30 | Agent Coordination | Communication, handoffs, shared state, coordination and result aggregation. |
| [Week 03](week-03/README.md) | 31 | Review and Coordination Failures | Verification agents, conflicting results, coordination loops and execution budgets. |
| [Week 04](week-04/README.md) | 32 | Multi-Agent Evaluation and Assessment | Quality, latency, cost, reliability, baseline comparisons and module assessment. |

## Module project

Your planned module deliverable is the Multi-Agent Research and Review System. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
