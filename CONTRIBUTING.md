# Contributing

Welcome! Contributions that improve accuracy, accessibility, test coverage, documentation and reproducibility are encouraged.

1. Open an issue describing the change, unless it is a small typo fix.
2. Create a branch and make focused changes.
3. Run relevant tests and document tested Python and dependency versions.
4. Submit a pull request with a clear description and actual evidence.

Do not submit secrets, fabricated execution outputs, copyrighted assets without permission or claims of production readiness without supporting tests. Be respectful and constructive.
