# Module 07. Model Context Protocol and Interoperability

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 25 to 28 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 25 | MCP Architecture | Clients, servers, tools, resources, prompts and capability discovery. |
| [Week 02](week-02/README.md) | 26 | MCP Server Implementation | Capability definitions, request validation, server implementation and predictable results. |
| [Week 03](week-03/README.md) | 27 | MCP Client Integration and Security | Client connections, authentication, authorization and trust boundaries. |
| [Week 04](week-04/README.md) | 28 | Interoperability Testing and Assessment | Client-server integration testing, failure investigation, secure interoperability and module assessment. |

## Module project

Your planned module deliverable is the Custom MCP Server and Client. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
