# Screenshot and Evidence Standards

Capture actual terminal output, passing tests, relevant errors and their resolution, API responses with sensitive fields removed, agent traces, and working application behavior. Use descriptive filenames and captions explaining what each image proves.

Do not capture screenshots for trivial commands unless they establish a meaningful prerequisite. Never fabricate screenshots, logs, benchmark results or completed tests.

Before publication, redact API keys, access tokens, personal data, cloud account identifiers, public IPs where sensitive, internal URLs and private documents. Review screenshots and terminal history as carefully as source code.
