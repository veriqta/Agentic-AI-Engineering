# Project Standards

Every project must document: problem statement; learning objectives; architecture; prerequisites; setup; complete source; input and output examples; tests; error cases; security considerations; cost implications; limitations; real evidence; next steps.

## Practical review rubric

| Area | Questions |
|---|---|
| Correctness | Does it solve the documented task? |
| Reproducibility | Can another learner run it? |
| Understanding | Are the important decisions explained? |
| Testing | Are success and failure paths covered? |
| Security | Are permissions, data and secrets handled safely? |
| Operations | Can failures be observed and diagnosed? |
| Evidence | Are results authentic and appropriately redacted? |

A project is **verified** only when its required tests and actual outputs have been reviewed. Educational demos are not automatically production-ready.
