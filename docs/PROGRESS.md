## Keep your own learning record

Record each lesson separately. Use these states to identify what you have actually established:

| State | Evidence you need |
|---|---|
| Planned | A defined objective and next activity |
| In progress | Work has started; requirements remain |
| Executed | You ran the implementation and saved the actual result |
| Verified | You checked the result against stated requirements |
| Assessed | You completed and reviewed the practical and conceptual assessment |
| Completed | All lesson requirements and essential understanding are established |
| Published | Reviewed material is merged and available on the public main branch |

Execution, assessment and publication are separate dimensions. You can publish an educational reference while your own assessment remains open. You can pass a lesson assessment while the rest of its week is unfinished. Complete Module 01 only after its four weeks, integrated project and module assessment are satisfied.
