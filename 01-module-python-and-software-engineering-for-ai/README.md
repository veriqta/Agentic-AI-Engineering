# Module 01. Python and Software Engineering for AI

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 01 to 04 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 01 | Python Foundations | Programs, terminal commands, variables, data types, conditions, functions, parameters, return values and introductory debugging. |
| [Week 02](week-02/README.md) | 02 | Professional Python Development | Collections, modules, files, JSON, virtual environments, dependencies, validation, exceptions, logging and automated tests. |
| [Week 03](week-03/README.md) | 03 | APIs and External Systems | HTTP requests, response codes, JSON contracts, configuration, credential handling, timeouts and network failures. |
| [Week 04](week-04/README.md) | 04 | Integrated Application and Assessment | Project integration, test coverage, debugging, security review, reproducibility and the module assessment. |

## Module project

Your planned module deliverable is the Student Support Automation Toolkit. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
