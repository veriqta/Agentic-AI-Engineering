# 09. Complete Source

[first_agent.py](first_agent.py) contains the introductory welcome script. [support_briefing.py](support_briefing.py) contains the Day 01 project milestone. Both use sample information and no external services.

Read the [notes](../01-notes.md), [guided lab](../02-follow-along-lab.md) and [walkthrough](../03-code-walkthrough.md) before running the files. From the day-01 directory, use python3 followed by the 09-source script path. The lab explains each command and expected output.

No package installation or executable permission change is required. The scripts execute top-level statements; they are not yet reusable import-safe libraries. Later classes will introduce functions and execution guards when those responsibilities are needed.
