# Complete Day 01 Project

This folder contains three runnable files. first_agent.py prints the introductory welcome. support_briefing.py displays the sample support request. test_day01.py verifies both scripts.

In your own practice work, create a folder named veriqta-day-01 and put the same three files directly inside it. You do not need numbered source or test folders. The word project here is a repository organization label, not a Python command or special language feature.

Follow the [complete project tutorial](../04-project.md) from its first step. It teaches every command, supplies every file and states what to expect. The [code walkthrough](../03-code-walkthrough.md) explains how the implementation works.
