# Module 02. LLMs and Agent Fundamentals

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 05 to 08 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 05 | LLM Foundations | Model behavior, tokens, context windows, inference, limitations and uncertainty. |
| [Week 02](week-02/README.md) | 06 | Model API Integration | Model requests and responses, configuration, prompt design, structured outputs and validation. |
| [Week 03](week-03/README.md) | 07 | Tool Calling and Agent Loops | Tool definitions, arguments, results, execution loops, stopping conditions and execution limits. |
| [Week 04](week-04/README.md) | 08 | Support Agent Integration and Assessment | Model and tool integration, unreliable outputs, end-to-end testing and module assessment. |

## Module project

Your planned module deliverable is the First LLM-Powered Support Agent. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
