# Module 04. Memory, State and Context Engineering

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 13 to 16 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 13 | Conversation and Session State | Message history, session identity, state ownership and context limits. |
| [Week 02](week-02/README.md) | 14 | Persistent Storage | Database fundamentals, records, queries, conversation storage and data separation. |
| [Week 03](week-03/README.md) | 15 | Context and Memory Management | Context selection, summarization, memory retrieval, retention and privacy. |
| [Week 04](week-04/README.md) | 16 | Checkpoints, Recovery and Assessment | State transitions, checkpoints, interrupted workflows, resumption and module assessment. |

## Module project

Your planned module deliverable is the Stateful Learning Assistant. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
