# Module 06. Agent Orchestration and Frameworks

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 21 to 24 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 21 | Orchestration Fundamentals | Deterministic workflows, planning, agent loops, routing, state and termination. |
| [Week 02](week-02/README.md) | 22 | OpenAI Agents SDK | Agent configuration, tools, handoffs and execution controls. |
| [Week 03](week-03/README.md) | 23 | LangGraph and LangChain | Graph-based execution, reusable components, workflow state and framework trade-offs. |
| [Week 04](week-04/README.md) | 24 | Workflow Integration and Assessment | Human approval, failure recovery, framework comparison and module assessment. |

## Module project

Your planned module deliverable is the Workflow Orchestration Agent. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
