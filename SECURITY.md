# Security Policy

This is an educational repository. Do not publish secrets, private datasets, customer information, credentials or unredacted infrastructure identifiers. Use environment variables and local `.env` files excluded by `.gitignore`.

Treat retrieved documents, web pages, tool outputs and model responses as untrusted input. Require explicit authorization and human review for sensitive external actions. Follow least privilege and test prompt-injection resistance.

For a suspected security issue, avoid posting exploit details or secrets in a public issue. Contact the repository maintainers through an appropriate private channel.
