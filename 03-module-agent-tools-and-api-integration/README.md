# Module 03. Agent Tools and API Integration

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 09 to 12 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 09 | Tool Interface Design | REST APIs, schemas, required fields, input validation and predictable results. |
| [Week 02](week-02/README.md) | 10 | Authentication and Authorization | Credentials, access scopes, least privilege and external service integration. |
| [Week 03](week-03/README.md) | 11 | Reliable Tool Execution | Timeouts, retries, backoff, rate limits, duplicate requests and idempotency. |
| [Week 04](week-04/README.md) | 12 | Multi-Tool Integration and Assessment | Coordinated external operations, partial failure, safe execution boundaries and module assessment. |

## Module project

Your planned module deliverable is the Multi-Tool Operations Assistant. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
