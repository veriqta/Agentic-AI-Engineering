# Module 11. Production Deployment and AgentOps

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 41 to 44 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 41 | Agent Service Development | FastAPI, validation, configuration, persistence and health checks. |
| [Week 02](week-02/README.md) | 42 | Packaging and Delivery | Docker, dependencies, CI/CD and environment separation. |
| [Week 03](week-03/README.md) | 43 | Cloud Operations | AWS deployment, queues, background workers, scaling and monitoring. |
| [Week 04](week-04/README.md) | 44 | Reliability and Operational Assessment | Rollback, recovery, runbooks, incident investigation and module assessment. |

## Module project

Your planned module deliverable is the Cloud-Deployed Agent Service. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
