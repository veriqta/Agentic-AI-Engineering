# Module 05. RAG and Knowledge Engineering

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 17 to 20 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 17 | Document Preparation | Document ingestion, parsing, metadata, chunking and document updates. |
| [Week 02](week-02/README.md) | 18 | Embeddings and Retrieval | Vector representations, similarity search, vector databases and retrieval filters. |
| [Week 03](week-03/README.md) | 19 | Retrieval Quality | Keyword and hybrid search, reranking, source attribution and retrieval evaluation. |
| [Week 04](week-04/README.md) | 20 | RAG Integration and Assessment | Grounded answers, missing evidence, unsupported claims, evaluation and module assessment. |

## Module project

Your planned module deliverable is the Document Intelligence Agent. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
