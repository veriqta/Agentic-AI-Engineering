# Module 10. Evaluation, Testing and Observability

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 37 to 40 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 37 | Evaluation Design | Requirements, representative datasets, reference outcomes and scoring criteria. |
| [Week 02](week-02/README.md) | 38 | Automated Agent Evaluation | Functional tests, tool-call accuracy, regression checks and evaluator limitations. |
| [Week 03](week-03/README.md) | 39 | Observability and Failure Analysis | Structured logs, traces, latency, token usage, cost and production failure analysis. |
| [Week 04](week-04/README.md) | 40 | Quality Gates and Assessment | Version comparisons, regression investigation, release criteria and module assessment. |

## Module project

Your planned module deliverable is the Agent Evaluation and Monitoring Platform. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
