# Module 10: Evaluation & Observability

**Duration:** Four weeks. **Core topics:** Datasets, regression, traces, metrics, cost.

**Portfolio milestone:** Agent Quality Dashboard.

## Module goals

Understand the architecture, implement a working system, evaluate its behavior, and explain security, reliability and operational trade-offs.

## Weekly learning path

1. Core concepts and first runnable baseline.
2. Practical integration and project development.
3. Failure handling, testing, security and observability.
4. Verified portfolio milestone, documentation and independent assessment.
