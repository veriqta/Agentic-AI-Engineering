# Week 01: Python Foundations and the Student Support Response Toolkit

This week develops the first practical project in the 52-week Agentic AI Engineering program. Readers learn ordinary software foundations that later agents depend on: explicit inputs, reliable functions, predictable errors, machine-readable output and automated verification.

## Start with Lesson 01

Open [00, Lesson 01 classroom guide](01-lessons/01-student-support/00-README.md). The numbered reading order contains comprehensive notes, command foundations, a guided build, a complete code walkthrough, automated testing, the weekly follow-along project, troubleshooting, exercises, knowledge checks, separate answers, practical assessment, verification and portfolio guidance.

## Weekly project and lesson milestones

The **VERIQTA Student Support Response Toolkit** is the Week 01 project. Each lesson contributes a bounded milestone; the week does not create unrelated small projects merely to increase counts. Lesson 01 builds the response component, suite and evidence workflow. Later foundation milestones can extend structured student data and file handling before the week is assessed.

## Suggested study schedule

| Session | Focus | Evidence |
|---|---|---|
| A, about 60 minutes | Foundations, environment and guided implementation | Actual valid execution and data-flow trace |
| B, about 60 minutes | Walkthrough, input contract and test suite | Tests and interpreted outcomes |
| C, about 60 minutes | Weekly project evidence and debugging | Captured failure, correction and recovery |
| D, about 60 minutes | Exercises, knowledge check and assessment | Reviewed reasoning and practical criteria |

Times are guides, not deadlines. Additional study may be needed. Do not claim the whole week is completed because the response script passes nine tests.

## Progress and boundaries

Implementation execution is a verified milestone. The detailed understanding review and learner assessment remain open. Week 01 and Module 01 remain in progress. This is a simulated support-response application, not an authenticated payment service or LLM agent.
