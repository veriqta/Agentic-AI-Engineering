# Weekly Project: VERIQTA Student Support Response Toolkit

You will integrate Week 01's milestones into one usable support-response tool. Sarah supplies a name and a simulated payment status. Your application validates the information, applies a defined rule, returns JSON and reports controlled failures. You will prove defined behavior with tests and investigate a regression.

## Runtime boundary

This project does not query a provider, use an LLM or grant real course access. Paid is simulated input. Its value is the tested software foundation you can later connect to trusted external systems.
