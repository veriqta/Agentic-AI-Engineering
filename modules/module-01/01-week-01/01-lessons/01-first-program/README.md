# Lesson 01: Your First Python Program

Module 01, Week 01. Suggested study time: approximately 60 minutes. You will execute a program and distinguish a shell command from Python source.

## Your engineering problem

You are building a support tool for VERIQTA Academy. Your first milestone is a welcome display that proves you can save and execute a Python program. Later lessons add the logic needed to answer Sarah’s course-access request. You will establish the execution foundation before integrating those responsibilities.

## Learning objectives

- You will execute a program and distinguish a shell command from Python source.
- Explain the important commands and code before you run them.
- Compare actual behavior with the stated contract and investigate differences.
- Complete the practical check using evidence and reasoning.

## Prerequisites

You need a Linux terminal, Python and permission to create a practice folder. No previous Python knowledge is required. No model account, payment credential or third-party package is required.

## Study in order

1. Read [01, teaching notes](01-notes.md).
2. Build the milestone using [02, guided lab](02-follow-along-lab.md).
3. Trace the implementation with [03, code walkthrough](03-code-walkthrough.md).
4. Attempt [04, knowledge check](04-knowledge-check.md) before reading [05, explanations](05-knowledge-answers.md).
5. Complete [06, practical assessment](06-practical-assessment.md); use [07, troubleshooting](07-troubleshooting.md) and [08, exercises](08-exercises.md) when needed.

## Your practical outcome

Explain which program runs and which statement produces the output. Keep your own result and review notes. You are not marked completed merely because a reference result is available.
