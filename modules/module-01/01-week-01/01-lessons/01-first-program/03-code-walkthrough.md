## Follow one execution

The shell starts python3 with first_agent.py as its file argument. Python reads the file and reaches print. The text inside quotes is a string literal. The parentheses supply that string to print, which writes it to stdout followed by a newline. Once the file ends, Python exits normally. The program contains no user input, model call or background agent.

The filename identifies the source file. The words inside the quotes identify the output. Changing a filename does not change the message; changing the string does. A comment beginning with # is an explanation for a person, not another command.

## Understand the boundary

Your terminal displays the result but does not prove you understand the program. To explain this milestone, identify the shell command, the Python statement and the produced text. You do not need to memorize a long script. This simple boundary will remain the same when the file later contains functions and tests.
