# Lesson 05: Build a Command-Line Support Application

Module 01, Week 01. Suggested study time: approximately 60 minutes. You will connect reusable functions to terminal arguments, JSON output and diagnostics.

## Your engineering problem

You are building a support tool for VERIQTA Academy. Sarah needs a clear response about course access. In this lesson you will add one responsibility to that tool, understand it and verify its behavior before integrating the next responsibility.

## Learning objectives

- You will connect reusable functions to terminal arguments, JSON output and diagnostics.
- Explain the important commands and code before you run them.
- Compare actual behavior with the stated contract and investigate differences.
- Complete the practical check using evidence and reasoning.

## Prerequisites

Complete the preceding lesson or demonstrate its outcomes before adding this milestone. No model account, payment credential or third-party package is required.

## Study in order

1. Read [01, teaching notes](01-notes.md).
2. Build the milestone using [02, guided lab](02-follow-along-lab.md).
3. Trace the implementation with [03, code walkthrough](03-code-walkthrough.md).
4. Attempt [04, knowledge check](04-knowledge-check.md) before reading [05, explanations](05-knowledge-answers.md).
5. Complete [06, practical assessment](06-practical-assessment.md); use [07, troubleshooting](07-troubleshooting.md) and [08, exercises](08-exercises.md) when needed.

## Your practical outcome

Trace a request from argparse through the helpers to JSON, including a rejected input. Keep your own result and review notes. You are not marked completed merely because a reference result is available.
