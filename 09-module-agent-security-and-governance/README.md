# Module 09. Agent Security and Governance

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 33 to 36 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 33 | Agent Threat Modeling | Assets, attackers, trust boundaries, prompt injection, misuse and data leakage. |
| [Week 02](week-02/README.md) | 34 | Permission and Execution Controls | Least privilege, authorization, tool permission boundaries, sandboxing and human approval. |
| [Week 03](week-03/README.md) | 35 | Data Protection and Governance | Credential handling, privacy, audit records, governance and operational controls. |
| [Week 04](week-04/README.md) | 36 | Security Testing and Assessment | Adversarial scenarios, control verification, remediation, residual risk and module assessment. |

## Module project

Your planned module deliverable is the Security-Hardened Agent. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
