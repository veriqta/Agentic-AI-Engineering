# Module 12. Advanced Agentic Systems

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 45 to 48 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 45 | Browser Automation | Page interaction, selectors, sessions, verification and permitted actions. |
| [Week 02](week-02/README.md) | 46 | Computer Use and Multimodal Systems | Screenshots, documents, visual interpretation, computer interaction and action uncertainty. |
| [Week 03](week-03/README.md) | 47 | Long-Running Agent Operations | Task persistence, checkpoints, cancellation, resumption, error recovery and execution budgets. |
| [Week 04](week-04/README.md) | 48 | Supervised Integration and Assessment | Human oversight, consequential actions, recovery, end-to-end verification and module assessment. |

## Module project

Your planned module deliverable is the Supervised Operations Agent. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
