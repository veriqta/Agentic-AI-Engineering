# Module 13. Capstone and Engineering Portfolio

You will study this module over four weeks, with seven daily classes in each week. It covers course Weeks 49 to 52 and contains 28 planned daily class locations.

## Four-week curriculum

| Week within this module | Course week | Subject | Scope |
|---|---|---|---|
| [Week 01](week-01/README.md) | 49 | Capstone Requirements and Architecture | Users, boundaries, acceptance criteria, threat modeling and operational requirements. |
| [Week 02](week-02/README.md) | 50 | Capstone Implementation and Integration | Core workflows, tools, retrieval, storage, state and interfaces. |
| [Week 03](week-03/README.md) | 51 | Engineering Validation | Security review, evaluations, cloud deployment, monitoring and incident simulation. |
| [Week 04](week-04/README.md) | 52 | Final Assessment and Portfolio | System demonstration, design decisions, evidence, portfolio presentation and technical interview practice. |

## Module project

Your planned module deliverable is the Production-Oriented Agentic AI Platform. Daily classes will develop the skills and project milestones needed for that deliverable. A working example or a passing test suite alone does not complete the module assessment.

## Start the module

Open [Week 01](week-01/README.md), then Day 01. Daily notes, guided labs, implementation explanations, exercises and assessments will be added to their day folders as classes are developed. This publication establishes the structure; it does not claim those classes have been authored or completed.
